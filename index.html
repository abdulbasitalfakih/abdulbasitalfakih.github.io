Proyek TJKT · Yang Telah Saya Kerjakan

🌩️ Deploy Web Server di AWS EC2

Proyek ini saya kerjakan untuk memahami cloud computing. Saya membuat instance EC2 t2.micro, mengkonfigurasi security group untuk membuka port HTTP/SSH, dan mendeploy website statis menggunakan Apache. Saya juga mengatur Elastic IP agar website bisa diakses secara publik.
AWS EC2 Apache Security Group Linux

🔄 Simulasi Jaringan Kantor MikroTik

Saya membangun simulasi jaringan kantor dengan 3 departemen (IT, HR, Finance) menggunakan VLAN di MikroTik RouterOS. Konfigurasi mencakup routing antar VLAN, firewall filter untuk membatasi akses, bandwidth management menggunakan queue tree, dan hotspot untuk guest wifi.
MikroTik RouterOS VLAN Firewall Queue Tree

🐧 Debian Server LAMP & DNS Server

Proyek ini mengimplementasikan server Debian 11 sebagai web server dan DNS server. Saya menginstal LAMP stack (Apache, MySQL, PHP), mengkonfigurasi virtual host untuk multiple domain, serta setup Bind9 untuk DNS internal. Semua dikelola via SSH dan diotomatisasi dengan bash script untuk backup.
Debian 11 Apache2 Bind9 Bash Script

🛡️ Vulnerability Assessment & Hardening Lab

Saya melakukan vulnerability scanning menggunakan Nmap dan OpenVAS pada jaringan lab. Hasil scanning dianalisis lalu dilakukan hardening: menutup port tidak terpakai, mengkonfigurasi firewall iptables, dan menerapkan best practice keamanan server. Proyek ini meningkatkan pemahaman saya tentang keamanan siber.
Nmap OpenVAS IPTables Kali Linux

📝 Website Profil Sekolah dengan WordPress

WordPress Elementor MySQL SEO
