MikroTik · RouterOS

Network Engineering & Administration

📌 Apa yang Saya Kuasai?

Saya telah mempelajari dan mempraktikkan MikroTik RouterOS untuk keperluan administrasi jaringan skala kecil hingga menengah. Berikut adalah detail kompetensi yang saya miliki:

  • Routing & NAT - Konfigurasi routing statis/dinamis, NAT untuk sharing internet
  • Firewall Filter - Membatasi akses berdasarkan source/destination, port, protocol
  • Bandwidth Management - Simple Queue dan Queue Tree untuk limitasi kecepatan
  • Hotspot - Manajemen user untuk akses wifi publik
  • VLAN (Virtual LAN) - Segmentasi jaringan untuk keamanan dan efisiensi
  • Bridge & Bonding - Menggabungkan interface untuk redundansi
  • DHCP Server - Pembagian IP address otomatis ke client

🛠️ Tools yang Saya Gunakan

  • MikroTik RouterOS (Winbox & CLI)
  • GNS3 / EVE-NG untuk simulasi jaringan
  • MikroTik CHR (Cloud Hosted Router)

Debian Server

Linux Server Administration

📌 Apa yang Saya Kuasai?

Saya telah menguasai administrasi server Debian untuk kebutuhan web server, DNS server, dan DHCP server. Berikut detail kompetensinya:

  • LAMP Stack - Instalasi & konfigurasi Apache2, MySQL/MariaDB, PHP

  • Manajemen User & Permission - Keamanan akses file dan direktori

  • PuTTY / Terminal untuk SSH
